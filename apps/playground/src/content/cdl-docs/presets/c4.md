# c4 preset

`c4` preset は C4 model (Context / Container / Component / Code の 4 階層でソフトウェアアーキテクチャを表す手法) の system context レベルを表現するための preset です。
mermaid `C4Context` に対応し、 person / system / external system を既存の NodeKind (`person` / `service` / `api` / `database` / `cdn` 等) で区別します。

## いつ使うか

- システム全体の context (ユーザー / 自社システム / 外部システム) を 1 枚で示したい
- DDD の bounded context 境界を視覚化したい
- AWS / Azure deployment 図と組み合わせて使いたい

現状は topology preset と同じ group layout で描画される簡略実装で、 boundary 表現は top-level `lanes` / `groups` の `contain: true` で行います。
完全な C4 (Container / Component diagram、 boundary 外枠) は将来 PR で専用 layout を追加予定です。

## 最小例

::: tabs

@@@ humans 👤 For humans

```text
title: "System Context"
type: c4

actors:
  - User: { kind: person, subtitle: "End user" }
  - Web: { kind: service, subtitle: "Frontend" }
  - API: { kind: api, subtitle: "Backend" }
  - DB: { kind: database, subtitle: "PostgreSQL" }

flow:
  - User -> Web: "uses"
  - Web -> API: "calls"
  - API -> DB: "reads"
```

@@@ llm 🤖 For LLM

```yaml
preset: c4
intent: "C4 model system context diagram"
actors:
  - { id: User, kind: person, role: end-user }
  - { id: Web, kind: service, role: frontend }
  - { id: API, kind: api, role: backend }
  - { id: DB, kind: database, role: persistence }
flow:
  - { from: User, to: Web, label: uses }
  - { from: Web, to: API, label: calls }
  - { from: API, to: DB, label: reads }
constraints:
  - "person = ユーザー、 service / api = 自社システム、 cdn / external = 外部システム"
  - "boundary 表現は top-level lanes / groups の contain: true"
  - "現状は C4 context のみ、 Container / Component は将来 PR"
```

:::
