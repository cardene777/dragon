# 意匠の見本

## 宅配の筋書き

荷主が集荷を頼み、営業所が受け付けて送り状を起こし、配送便に積んで届ける。
受取人が在宅なら荷物を受け取り、不在なら配送便が持ち戻って翌日もう一度届ける。
契約、荷物、配送便、営業所、受付、仕分け、配送状態の関係と、受付 API、台帳、追跡、通知など配送システムの部品を同じ筋書きから描いている。
配達数、一度で届いた割合、再配達を減らす案、作業日程、営業所の階層、集荷から配達までの呼び出し順も、この宅配を別の図種で見たものである。
