# er-demo

表と表の繋がりを示す図。 実体を表の形の箱で並べ、端の印で個数を表す。

## 決めたこと

箱の幅は 400 で揃える。
今光っている箱だけ 412 になるのは枠が 1.25 から 3 に太る分で、箱そのものは広げていない。

箱の高さは中の行数で決まる。
列 4 本の実体が 442、見出しを持つ実体が 498。

角の丸みは 16 で全ての箱に同じ値を当てる。
実体ごとに変えると、同じ図の中で違う種類の箱に見える。

段は 4 つ。
段が進むごとに繋がりが 1 本ずつ増え、実体は最初の段から出したままにする。

動きの時間は engine が要素に持たせている値をそのまま使う。
箱が `opacity 120ms` と `transform 200ms`、線が `stroke 280ms` と `stroke-width 280ms`。

## 見送ったこと

今光っている箱を一回り大きくする案。
隣の箱との間が詰まって行の字が読みにくくなるので、太らせるのは枠だけにした。

繋がりの字を線の真ん中に置く案。
実体が近いと線が短く、字が線からはみ出す。
実体の上に置く形を保つ。
