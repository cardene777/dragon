# er-demo

表と表の繋がりを示す図。 実体を表の形の箱で並べ、端の印で個数を表す。

## 決めたこと

繋がりの字が乗る下地は、箱と同じ面にする。
色は `--d-surface` (箱の面) を使い、`--d-bg` (台) より明るい側に来る形で明暗を揃える。

**色は変数の名前で書く**。 16 進の値を書くと、engine の配色を変えた時にここだけ古い値が残る
(実際に `#1531` で 4 値とも古くなった)。 変数の名前なら、指す先が変わっても記述は正しいまま。

繋がりの名前は日本語で書く。
`注文する` / `明細を持つ` / `上司`。

箱の幅は 400 で揃える。
今光っている箱だけ 412 になるのは枠が太る分で、箱そのものは広げていない。

箱の高さは中の行数で決まる。
列 4 本の実体が 442、見出しを持つ実体が 498。

角の丸みは 16 で全ての箱に同じ値を当てる。

枠の太さは静かな箱が 1.75、今光っている箱が 2.5。

段は 4 つ。
段が進むごとに繋がりが 1 本ずつ増え、実体は最初の段から出したままにする。

動きの時間は engine が要素に持たせている値をそのまま使う。
箱が `opacity 120ms` と `transform 200ms`、線が `stroke 280ms` と `stroke-width 280ms`。

## 見送ったこと

下地を台と同じ面にする案。
最も静かになるが、下地が線を隠している役目が見た目に出ないので採らなかった。

下地をやめて字だけにする案。
一番軽いが、ER 図は実体が近く線が短いため、字が線の上に乗って読めなくなる。

繋がりの名前を大文字英語のまま残す案。
ER 図の慣習には合うが、同じカタログの時系列のやり取りの図が日本語なので、ER 図だけ語が混ざる。

英語を主にして日本語を添える案。
両方残せるが、短い線の上で字が 2 行になり場所を取る。
