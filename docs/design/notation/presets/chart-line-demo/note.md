# chart-line-demo

時系列の推移を線で示す図。 値を点で置き、隣どうしを線で結ぶ。

## 決めたこと

図全体を 1 つの箱に入れる。 幅 640、高さ 368、角の丸み 16、枠の太さ 2.5。
枠を持たせるのは、図表が数の集まりであって関係の図ではないことを示すため =
`er-demo` や `infra-demo` の箱は「もの」 を表すが、この枠は「1 枚の図表」 を囲む。

枠の太さは 2.5 の 1 値のみ。 関係の図が静かな箱 1.75 と光っている箱 2.5 を使い分けるのに対し、
図表は箱が 1 つしかないので使い分ける相手がいない。

折れ線の太さは 2.5。 枠と同じ値にした = 枠より太いと図表そのものより線が目立ち、
細いと 4 点を結ぶ線が枠の中で沈む。

値の字は 11。 点に添える数で、軸の目盛と同じ大きさにしない = 目盛は場所を示す添え物、
節の値は読ませたい数なので、太さ (`font-weight` 600) で差を付けて大きさは揃えない。

段は 2 つ。 1 段目で計画の線を起点から引き、2 段目で実績に置き換える。
線を引き直さず点の高さだけを動かすので、どこが計画と違ったかが動きで判る。

色は枠と線に `--cdl-tone-accent`、値の字に `--cdl-text`、面に `--cdl-node-fill`。
台は `--cdl-canvas-bg`。 図表の色 (`--cdl-chart-1` 〜 `--cdl-chart-6`) はこの図では使わない =
系列が 1 本なので区別する相手がいない。

動きの時間は engine が要素に持たせている値をそのまま使う。
箱が `opacity 120ms` と `transform 200ms`、線が `stroke 280ms` と `stroke-width 280ms`。

## 見送ったこと

目盛を読み手が使う数 (1000 / 1250 / 1500) に丸める案。
いまは最小値と最大値を 4 等分するため `900 / 1113 / 1325 / 1538 / 1750` になり、
半端な数が並ぶ。 丸める方が読みやすいが、目盛の刻み方は engine が決めており、
意匠帳の側から指定する口を持たない。 揃えるなら engine を直す別の作業になる。

節に添える数の位置を点の上に揃える案。
いまは `1,400` と `1,750` が点の上、`1,250` と `900` が点の下に出る。
上に揃えると目が横に流れるが、線を避ける規則を外すことになり、
下り坂の区間で数が線に重なる。

下端の横線を消す案。
`900` の高さに引かれる線が他の目盛線 (点線) より濃い実線で、軸に見える。
0 ではなく最小値の位置なので、軸と読むと `900` から `1,750` への伸びが
実際の 1.9 倍より大きく見える。 ただしこれも engine が引く線で、この図から消せない。

系列を 2 本にして計画と実績を並べる案。
段で置き換える形をやめて 2 本同時に見せると、差が一目で判る。
ただし段の動きで「置き換わる」 ことを示す形がこの図の主題なので、
並べると別の図になる。
