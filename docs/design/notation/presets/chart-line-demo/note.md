# chart-line-demo

時系列の推移を線で示す図。 値を点で置き、 隣どうしを線で結ぶ。
段で計画を実績に置き換えるので、 読ませたいのは値そのものではなく **2 つの差**。

## 決めたこと

目盛は全段で 1 度だけ決める。 その段の値から測り直さない。

測り直す形では、 最小と最大の点が段をまたいで動かない。
計画 1,000 が実績 900 に下がっても、 計画 1,600 が実績 1,750 に上がっても、
どちらも目盛ごと動くので図の上の高さが変わらなかった。
差を読ませる図で、 差が最も大きい両端から差が消えていた。

目盛の刻みは読み手が使う数に丸める。
この図では `750 / 1,000 / 1,250 / 1,500 / 1,750` の 5 本。
最小と最大を 4 等分する形では `900 / 1113 / 1325 / 1538 / 1750` と半端な数が並ぶ。

目盛の数字と点に添える数は同じ書き方にする。 どちらも 3 桁区切り。
片方だけ区切ると、 同じ数が `1750` と `1,750` の 2 通りで縦に並ぶ。

目盛線は 5 本、 太さ 0.75、 点線 (3 3)、 濃さ 0.65。 色は `--cdl-divider`。

**実線は 1 本も引かない**。
以前は最小値の高さと左端に濃い実線 (太さ 1.25) を引いていたが、
下端は 0 ではないのに軸に見えるため、 900 から 1,750 への伸びが実際の 1.9 倍より大きく感じる。

**図表を囲む枠を持ち**、 図表がどこからどこまでかを示す。
太さは光っている時 1.5、 光っていない時 1。 色は `--cdl-divider`、 面は `--cdl-node-fill`。
この図は 2 段とも光っているので、 実測できるのは 1.5 のほう。
折れ線 (光っている時 3) より細いので、 読ませたい線のほうが目立つ。

見本帳の画面では `cdl-theme.css` が `!important` で上書きし、 光っている枠は太さ 2.5、 色は `--d-accent` になる。
意匠帳と見本帳で枠の見え方が違うのはこのため。
どちらでも折れ線 (3) より細いので、 決めた向きは保たれている。

枠は「今光っている」 の手掛かりも兼ねていたので、 折れ線の太さに移した。
光っている時 3、 光っていない時 2。
この図は光った状態で焼いているので、 実測できるのは 3 のほう。
枠が戻った今は、 枠の太さと折れ線の太さの両方で示している。

端の点は軸から内側に入れる。 点の x は 96 / 256 / 416 / 576 で、 間隔は 160。
貼り付けると、 最初の点に添える数が縦軸の数字と横に並んで重なる。

点は白抜きの丸 (半径 5、 枠 2.5) の中に中実の丸 (半径 2.5)。

値の字は 11 で太さ 600、 月名は 12。
値は山なら点の上、 谷なら下に置く。 谷の値を上に出すと折れ線の内側に入って線に重なる。

線の先が点に着いた瞬間、 輪が広がりながら消え、 点の色が `--cdl-now` から
`--cdl-tone-accent` へ戻る。 光る窓は着いてからの進みが 0 以上 0.12 未満。
時間ではなく進みで決まるので、 静止した書き出しでも同じ絵になる。

色は枠と線に `--cdl-tone-accent`、 値の字に `--cdl-text`、 目盛の数字に `--cdl-text-dim`。
台は `--cdl-canvas-bg`。 図表の色 (`--cdl-chart-1` 〜 `--cdl-chart-6`) はこの図では使わない =
系列が 1 本なので区別する相手がいない。

段は 2 つ。 1 段目で計画、 2 段目で実績に置き換える。
線の動きは engine が要素に持たせている値をそのまま使う (`stroke` と `stroke-width` が 280ms)。

図の枠は 792 × 488、 原点は -28 , 68。

## 見送ったこと

系列を 2 本にして計画と実績を並べる案。
段で置き換える形をやめて 2 本同時に見せると差が一目で判る。
ただし段の動きで「置き換わる」 ことを示すのがこの図の主題なので、 並べると別の図になる。

複数系列の意匠は別に決めてある = 実績を実線、 計画を薄い破線にして間を塗り、
左上に線の形をそのまま出す凡例を置く。 この図はその形を採らない。

線の下を塗る案。
推移ではなく量として読めるようになるが、 目盛の下端が 0 でないため面積が値に比例しない。
塗ると比例して見えるので、 下端を 0 に置いた図でだけ使う。
指定 (`chartFillUnder`) としては engine が持っており、 この図では書かない。

粒が線をなぞる案。
線の上を点が抜け、 先端に着いた瞬間に光る。 どちらへ向かう図かを示したい時に効くが、
4 点しかないこの図では線を目で追うほうが早い。
指定 (`chartTrace`) としては engine が持っており、 この図では書かない。

値の字を全て点の上に揃える案。
目が横に流れるが、 下り坂の区間で数が線に重なる。 山と谷で分ける規則を残した。

## 直した engine

以前この note は 3 件を「engine が決めており意匠帳の側から指定する口を持たない」 として見送っていた。
engine の修正でその判断が成立しなくなった点と、 後から差し戻された枠を記す。

| 前の判断 | いま |
|---|---|
| 目盛を読み手が使う数に丸める | 丸めている |
| 下端の横線を消す | 引いていない |
| 節に添える数の位置を揃える | 山と谷の規則として残す (これは今も見送り) |
| 図表を囲む枠を外す | 図表の範囲を示す枠が戻っている |

直した取り込みは `cardene777/cdl` の #667 / #668 / #669 で、 `0.31.0` に入っている。
枠の差し戻しは `cardene777/cdl` の #676 で、 `0.31.1` に入っている。
