# seq-demo

時系列のやり取りを縦の時間軸で並べる図。 役者を横に置き、時間を下へ流す。

## 決めたこと

**箱を持たない**。 この図は他の型と違い、`node-body` を 1 件も持たない。
役者は縦線とその頭の名前で表し、囲まない。 囲むと箱の図に見えて、時間が下へ流れる軸が弱まる。

縦線の間隔は 224 で全ての役者に同じ値を当てる。
やり取りの字が線の上に乗るため、間隔は字の長さではなく最も長い名前が収まる幅で決めた。

縦線の太さは 3。 区切り線 (役者の下を横に走る線) は 2 で、縦線より細くする。
縦線は最後まで伸びる軸で、区切り線は頭とやり取りを分ける境。 役割が違うので太さを分ける。

帯 (動いている間) は幅 52、角の丸み 4。
箱の丸み 16 より小さい値を当てる = 帯は箱ではなく、縦線が太った状態として見せる。

やり取りの線の太さは 2.5。 起点に半径 7 の丸を置き、線が出る側を示す。
矢だけだと向きは判るが、どちらが仕事を始めたかが読めない。

役者の名前は字 24、やり取りの字は 26。
**やり取りのほうが大きい**。 名前は 4 つしかなく一度読めば済むが、やり取りは 7 本あって
段ごとに 1 本ずつ読ませるため、目が最初に行く側を大きくした。

段は 7 つ。 やり取り 1 本につき 1 段で、帯は段に応じて伸び縮みする。
台帳の帯は途中で 1 度切れる = 手が空くことを帯の不在で示す。

色は線と帯に `--cdl-now` (今の段) を当て、済んだ段は `--cdl-tone-accent` に戻す。
字は `--cdl-text`、添えの名前は `--cdl-text-dim`、区切り線と縦線は `--cdl-divider`。

動きの時間は engine が要素に持たせている値をそのまま使う。
線が `stroke 280ms` と `stroke-width 280ms`。 箱を持たないので箱の動きは無い。

## 見送ったこと

役者を箱で囲む案。
どこからどこまでが 1 人かは判りやすくなるが、囲むと箱の図に見えて時間の軸が弱まる。
`er-demo` や `infra-demo` と同じ見た目になり、型の違いが読めなくなる。

帯の角を落とさず角ばらせる案。
縦線との繋がりは強くなるが、区切り線や矢と同じ直線の集まりに見えて、
「その間ずっと動いている」 という面の意味が出ない。

起点の丸を置かず矢だけにする案。
線は減って軽くなるが、自分宛ての言づて (`API` → `API`) で向きが読めなくなる。
行って戻る線は両端が同じ縦線に付くため、始まりの側を点で示さないと区別できない。

役者の名前をやり取りの字より大きくする案。
軸になる名前を大きく取るのが普通の並びだが、この図は段ごとにやり取りを 1 本ずつ読ませるので、
目が最初に行く側を大きくした。 名前は 4 つで一度読めば済む。

やり取りの字を線の上ではなく脇に寄せる案。
線が隠れずに済むが、7 本が縦に並ぶと字の左端が揃わず、どの線の説明かを目で辿ることになる。
