# dragon の図の描き方の決まり

どの図も、同じ部品を同じ使い方で並べる。
図ごとに部品を作り足す前に、ここにある部品で描けないかを確かめる。
決まりの多くは engine.js の部品が持っていて、図の側からは変えられない。

## 色

| 色の枠 | 役 | 例 |
|---|---|---|
| blue | 動きを始める側、送る側 | 送信元のチェーン、注文を出した側、main の枝 |
| amber | 間に立つ側、確かめる側 | Chainlink のネットワーク、支払い、投票 |
| green | 受け取る側、終わった状態 | 送信先のチェーン、配達完了、確定 |
| violet | 別の系統、第三者 | 認可サーバー、配送、作業の枝 |
| rose | 止める、取り消す、失敗 | キャンセル、返金、衝突 |
| slate | 人や中立の物 | 利用者のブラウザ |
| coin | 価値そのもの | トークン、代金 |

- 色の値は palettes.json の色味が持ち、図の file に色の値を書かない
- 1 枚に使う色の枠は 5 つまで。6 つ目が要る時は、同じ役の物を同じ色にまとめる
- 暗い背景は同じ色でも明るい背景より強く見えるので、暗い側は色の鮮やかさと区画に敷く色の量を明るい側より抑える。値を変えたら `calm-dark.mjs` の決め方で求め直し、見分けの検査 (`check-palettes.mjs`) を通す

## 部品と使い方

| 部品 | 決まり | 部品の名前 |
|---|---|---|
| 区画 | 場所か系統を表す時だけ横の帯で置く。名前は左上に印と 2 行まで | `E.band` |
| 箱 | 登場する物は全て高さ 72 の箱。印、名前、下の小さな字の 3 段 | `E.card` |
| 今の箱 | 縁に色、外に淡い光。下の小さな字が、その時に起きていることへ書き換わる | `E.card` の `on` と `swap` |
| 線 | 先に点線で道を見せ、その段で色の線を引き、流れる点で向きを見せる。済んだ線は薄く残す | `E.edge` |
| 線の名前 | その段の間だけ色付きの札で出し、済んだら消す。置き場所は線の中ほどの上か右で、部品が決める | `E.edge` の `label` |
| 段の番号 | その段が始まった時に塗って出し、済んだら縁取りで残す。まだ来ていない段の番号は出さない。置き場所はその段で引く線の始まりで、線の無い段は動く箱の左上の角 | `E.edge` が自動で置く / `E.stepAt` |
| 運ぶ物 | 線の上を走り、着いた先で次の同じ主役が出発するまで留まる。主役の最初の 1 つは図の始まりから出発点で待つ。メッセージや要求は封筒、名前のある値は札、価値は硬貨の 3 種だけ。封筒と札は、明るい背景では灰で塗る (黒で塗ると図で一番強い物になるため)。灰は色味の `carry` が持ち、`carry-light.mjs` が求める。暗い背景では字の色の白で塗る (灰は沈んで見え、白は暗い地で強く見えないため) | `E.edge` の `carry` |
| 箱の中の処理 | 線を作らず、箱の下の字の書き換えで見せる | `E.card` の `swap` |
| 中身の帯 | 図の下に 1 本。左に印と題、欄は細い線で区切り、上に欄の名前、下に値 | `E.stripBg` と `E.field` |
| 語り | 図の下に段の番号、題、区画の札、本文、呼び出し | engine が組む |

## 運ぶ物の続き方

主役 (`who`) ごとに、図のどこかに必ず 1 つ見えている。
封筒と札は既定で同じ主役 `main`、硬貨は `coin` になる。

| 書き方 | 消える時 | 使う場面 |
|---|---|---|
| 何も渡さない | 次の同じ主役が出発した瞬間 | 1 つの要求が箱から箱へ渡っていく |
| `until` | 渡した時刻 | 焼かれる硬貨のように、途中で役目を終える |
| `absorb: true` | 着いた先へ吸い込まれた時 | 届いた票のように、着いた先の状態の変化に置き換わる |
| `who` | 別の主役として数える | 応答と並んで控えへ入る写しのように、主役と同時に動く物 |

主役が運ぶ物でない図 (時間軸で確定が進む図など) は、運ぶ物を `absorb` で消してよい。
その時は、今の段で何が変わったかを箱の書き換えか時間軸の進みで見せる。

## 字

| 用途 | 大きさ |
|---|---|
| 箱の名前 | 13px |
| 区画の名前、帯の題 | 12.5px |
| 下の小さな字、線の名前、帯の値 | 11〜12px |
| 一番小さい字 (札、番号) | 10.5px |

10.5px より小さい字は使わない。

## 置き方

- 部品どうしは 10px 以上離す。線の名前が線より長くて入らない時だけ、`lp` で線の脇の空きへ寄せる
- 番号の位置を手で決めるのは、線も箱も持たない段 (例: 確定を待つ) だけにする
- 区画の帯の間は 10px、帯の内側の余白は 18px
