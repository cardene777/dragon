## `app.pen`

作り直す前の見本帳の画面 9 種の構成を描いた設計 file。 Pencil で開く。
画面は明るい側の 1 枚ずつだけを描き、 暗い側の frame は持たない。

見本帳の画面は #2983 で仮の 1 頁に置き換えたため、 **今の実装と突き合わせる検査は無い**。
新しい見本帳を組む時に、 前の画面の節の構成を読み返すために残している。

`.pen` の中の配色は色変数に集約してあり、 図の側はその変数を参照する。 直書きで残るのは透明だけなので、
**変数を直せば図全体に届く**。 変数は設計の図を描くための値で、 明暗の 2 値は持たない。

変数がいくつあるか、 どれだけの箇所が参照しているかは `.pen` を JSON として読んで数える。
ここに数を書き写すと、 変数を 1 つ足した日から古くなる。

中身は素の UTF-8 JSON で、 `JSON.parse` がそのまま通る。

`.pen` を Pencil で編集した後は **保存 (Cmd+S) が要る**。 MCP の `execute` は editor 上の
状態を変えるだけで、 disk には書かない。
