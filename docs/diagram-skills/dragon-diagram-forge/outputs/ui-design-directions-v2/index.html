ブロックは箱ではなく、状態遷移の証拠です。

Ethereum の block production では、Consensus Layer がタイミングと合意を扱い、Execution Layer が tx を実行して state root を返します。

02payload
EL が tx を実行し、結果を組み立てる。
03attestation
