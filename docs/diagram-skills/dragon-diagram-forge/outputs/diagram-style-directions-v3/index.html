説明図の
スタイル10案

複雑な説明は入れず、静止図としての雰囲気だけを比較します。Ethereum の「tx が実行され、state root になる」という同じ骨格を、10種類の絵柄で作っています。

01

Manim 黒板

黒背景、細い曲線、少数のラベル。3Blue1Brown に一番近い静かな数理図。

02

上質な技術記事

白い紙面、太い見出し、控えめな補助線。記事内に置いても浮かない図。

03

スイス・プロトコルシート

強いグリッド、番号、赤黒のアクセント。仕様書っぽく精密に見える。

04

ブループリント

設計図のような青い背景と白線。ブロック内部構造やネットワークに合う。

05

OLED コンソール

黒いプロダクトUI風。状態値やログを添える図に向くが、情報量は抑える。

06

フラット教材

明るい色面と単純な形。初学者向けに、怖くない印象で見せる。

07

Ledger Strip

ブロックやnonceのような順序を、横長の帯として見せる。流れではなく位置で理解させる。

08

式変形ボード

EIP-1559やMerkle proofのように、式や不変条件を主役にする。

09

Network Constellation

P2P伝播やvalidator集合を、星図のように見せる。関係性の美しさを優先。

10

Poster Graphic

大きな面と強いタイポ。プレゼンやSNS素材にしやすい、説明より印象重視の図。
