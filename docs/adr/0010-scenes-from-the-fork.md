# 1つの図の場面を、分かれる所から先だけを書く共通の部品にする

## 決めたこと

1つの図に、同じ箱の上で別の成り行きを辿る場面を3つまで持たせる。
箱と、全ての場面に共通の段は図で1回だけ書き、`scene <名前>`と`end`の間に、分かれる所から先のその場面だけの段を書く。
場面が止まる段には`stop <理由>`の行を書き、その段で場面が止まって理由の文を出す。
`scene`は全ての図の種類の共通の部品にし、`try`の図はこの部品を持たない。

見せ方は図の1行目の`[scenes: stack]`か`[scenes: pick]`で選び、書かない時は並べる見せ方で描く。
並べる見せ方は場面を縦に並べて同じ段の送りで同時に動かし、選ぶ見せ方は場面の名前の釦で選んだ1つの場面を段ごとに追う。
同じ箱は全ての場面で同じ位置に描き、並べる見せ方では共通の段の線を灰色、分かれた段から先の線を場面の色で描いて、分かれる箱か帯の上の縁に場面の色の「ここから分かれる」の札を掛ける。
分かれる位置は初めは図の上から下までの縦の点線で示したが、段の文と線の札と帯の間の矢印に重なったため、札に替えた (#4019)。
紙とPDFには、どちらの見せ方でも全ての場面を最後の段まで進めて縦に並べる。

## 選んだ案

分かれる所から先だけを場面に書くと、共通の段を場面の数だけ書き直さずに済み、どこで分かれるかが記法の`scene`の位置に現れる。
描く側もその位置を読めるので、分かれ目の札を掛ける箱と、場面の色で描く線の境を記法から決められる。
止まる理由を止まる段の中に書くと、止まる所と理由が同じ場所に並び、段の名前を2か所に書かない。

## 却下した案とその理由

| 案 | 却下した理由 |
|---|---|
| 箱は図で1回だけ書き、場面ごとに共通の段も含めて全ての段を書く | 共通の段を場面の数だけ書き直し、どこで分かれるかが記法から読めない |
| 場面ごとに箱も段も書き、場面ごとに小さな図を1つずつ持つ | 書く量が最も多く、同じ箱を同じ位置に描けない |
| `scene`の行の終わりに`[stop: <段の名前>, reason: <理由>]`を書く | 段の名前を2か所に書き、書き違えると止まる段がずれる |
| 時系列図の場面 (#3873) を先に終え、その形を全ての種類へ広げる | 1つの種類の形に引きずられ、他の種類で同じ書き方にならない |
| 共通の段の色を変えず、分かれる段の名前にだけ印を付ける | 図を見ただけでは分かれる位置が分からない |
| 場面の間で通り方が違う箱に印を付ける | 4つの箱のうち3つに印が付く例があり、印が目立たせる役を果たさない |
| 選ぶ見せ方の印刷では、選んでいた場面だけを描く | 選ばれていない場面が紙から消える |
