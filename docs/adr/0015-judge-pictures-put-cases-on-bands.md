# 判定の表の絵は例を帯に置き、幅728pxに収める

## 決めたこと

判定の表 (`judge`) を絵に書き出す時は、頁に置く表と違う形で描く。
例の名前と添え書きを、その例の✓と✕の行の上の帯に1行で置き、左の例の列を無くす。
表は枠の幅、地、字、✓と✕の絵柄、判定の札をSVGの要素で描き、`foreignObject`を使わない。

この形は`dragon export`のSVG、PNG、GIF、mp4と、編集画面と見本帳の書き出す窓の同じ4つの形に当てる。
今の形で幅728pxに収まる表にも当てる。
帯の形でも728pxを超える表は、728pxに収まる所で規則の列を分け、帯の形の表を縦に積む。
どの段にも例の帯を置き、判定の列は最後の段に置く。
`--step`と、段ごとに列を照らす動きは頁の表と同じにする。

頁に置く表、再生する表、`--format html`の頁は、字を縮めないHTMLの表のまま変えない。

## 選んだ案

HTMLで組んだ試作では、送金の見本 (英語、今の形で幅885px) も会員登録の見本 (日本語、759px) も、字を縮めず折り返さずに728pxへ収まり、最も小さい字が11pxのまま残った。
規則の列と判定が1つの表に並び、規則の列を縦に見比べられる。
READMEのような狭い枠でも、字が読める大きさ (`READABLE_PX` = 10.5px) を下回らない。

## 却下した案とその理由

| 案                                                                         | 却下した理由                                                                           |
| -------------------------------------------------------------------------- | -------------------------------------------------------------------------------------- |
| 今の表を描き、枠の幅へ表ごと縮める                                         | 英語の見本で外れた規則の番号と添え書きが9pxになり、読める大きさを下回る                |
| 字の大きさを保ち、規則の名前と値、添え書き、外れた値、止めた理由を折り返す | 語の途中で行が変わる所が多く、行の高さが揃わない                                       |
| 字の大きさを保ち、規則の列を分けて2つの表を縦に積む                        | 1つの例の✓と✕が2つの表に分かれ、絵の高さが最も高い                                     |
| 帯の形でも収まらない表を、字を縮めずに728pxより広い絵にする                | 狭い枠では絵ごと縮み、字が読める大きさを下回る                                         |
| 帯の形でも収まらない表を、最も小さい字が10.5pxになる所まで縮めてから分ける | 縮められるのは今の字で約5%だけで、表ごとに字の大きさが揃わなくなる                     |
| SVGだけを帯の形にし、PNG、GIF、mp4は今のHTMLの表を撮る形のまま             | READMEに多いPNGとGIFで字が読める大きさを下回り、同じ表の止め絵と動画で見た目が食い違う |
| 今の形で728pxに収まる表は今の形で描く                                      | 規則を1つ足すだけで表の形が変わる                                                      |
| 表の写しを`foreignObject`に包んだSVGを書く                                 | FigmaやInkscapeのようなブラウザでない道具では表が空になる (#3937の決めたこと)          |
