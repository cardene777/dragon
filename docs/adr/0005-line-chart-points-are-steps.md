# 折れ線の時間の点を図の段で書く

## 決めたこと

量の図の見た目に`[shape: line]`を足し、時間につれた量の変わりを折れ線で描く。
`item`の行は1本の線、`step`の行は時間の軸の点の1つ、`set <項目>: <値>`はその段の点の値にする。
段の題は横の軸の名前になり、値を書かない段は前の段の値を保つ。

## 選んだ案

折れ線のために新しい語を足さず、今の量の図の`item`と`step`と`set`で書く。
段を送ると、線が前の段の点から新しい段の点へ伸びる。
止めて置く図 (`figure: true`) は最後の段の形で全ての線を描き、段の題を横の軸の名前のまま残して、図の上の行に図の題を出す。
そのため量の図の`figure`の直し (`packages/dragon/src/kinds/chart.ts`) は、折れ線の見た目では段の題を図の題に替えない。

## 却下した案とその理由

| 案 | 却下した理由 |
|---|---|
| 項目ごとに値の列を1行で書く新しい語 (`series sales: 120 98 140`) と、横の軸の名前を並べる行を足す | 値の列は段に属さないので、段を送って線を伸ばす動きと、点ごとの`say`の説明を持てない。課題は書き方を今の`item`と`set`に合わせると決めている |
| 値を書かない段で線を切る | 今の量の図は値を書かない項目が前の段の値を保つ決まりで、折れ線だけが違うと全ての段で全ての値を書かせることになる |
| 止めて置く図で、ほかの量の図と同じく段の題を図の題に替える | 折れ線では段の題が横の軸の名前なので、替えると全ての軸の名前が図の題になる |
