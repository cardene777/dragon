# 図の下の値の欄の字を、線の札の印に4つの印を足して地の文とコードに分ける

## 決めたこと

日本語を含まない`strip`の値は、線の札 ([0008](0008-label-font-by-code-signs.md)) と同じ印を持つか数で始まる時と、次の4つの印のどれかを持つ時だけ等幅の字 (`TYPE.fieldValue`) で描く。

- 英字と数字が混ざる3字以上の語 (hashの`8b04f71`、`e5f8`、`tx3`)
- 途中で切った値の`…` (`Splx…`)
- `v`で始まる版 (`v2.4.0`)
- 英字と数に挟まれた`/` (道の`m/44'/60'`)

ほかの値は地の文の値として、日本語の値と同じ字 (`TYPE.fieldValueJa`) で描く。
印を持たない枝の名前、commitの名前、道の始まりの`m`のような値は、値をbacktickで囲めば等幅で描き、囲みは描かない。
日本語を含む値は、印があっても`TYPE.fieldValueJa`で描く。
決まりは線の札と同じ部品 (`packages/dragon/src/layout/code-text.ts`) が持ち、足した4つの印で線の札の字が変わる見本は無い。
版は`v`で始まる物に、道は`/`の前が英字の物に限るので、`send 0.05 WETH`や`passed 2/3`のような数を持つ地の文の札は地の文のまま描く。

円の図の真ん中の値と帯の値は別の部品が等幅の大きな字で描くので、この決まりの外にある。

## 選んだ案

値ごとに印で見分ける案を選んだ。
見本と検査の記法と部品の図の全てで、日本語を含まない値を欄ごとに重ねずに数えると、地の文の字になるのは34のfileの104件で、全て英語の普通の語になる。
hashと版と道と途中で切った値は印で等幅に残り、backtickで囲み直すのは見本の26か所 (枝の付け替えの図の`HEAD`の`main`と`feature`、まとめる図のcommitの名前、HDウォレットの図の道の始まりの`m`、部品の図の`HEAD`の`main`) で済む。

## 却下した案とその理由

| 案 | 却下した理由 |
|---|---|
| 印は足さず、版と道も含めて見本の34か所をbacktickで囲む | 書き手が版と道を書くたびにbacktickで囲む必要があり、囲み忘れた版と道は地の文の字になる |
| 印を2つ足し、枝の名前だけを囲み、commitの名前と道の始まりの`m`は地の文の字にする | 同じ図の中でcommitの名前の`E 2a7c9d0`は等幅、`E, D, B, A`は地の文の字になり、道も始まりの`m`だけ字が違う |
| 欄ごとに揃え、同じ欄に印のある値が1つでもあれば、その欄の値を全て等幅にする | 後の段の値で前の段の値の字が変わり、CCIPの図の`ID`の`not yet`のような地の文の値も等幅になる |
| backtickで囲んだ値だけを等幅にする | 見本の等幅にする値の多くをbacktickで囲み直すことになる |
