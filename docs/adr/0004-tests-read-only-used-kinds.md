# 検査が使う図の種類だけを読み、関係する検査を選ぶ命令を狭める

## 決めたこと

公開の描く関数 (`renderDiagram`など) は同期のまま、既定の入口と軽い入口は今どおり全ての図の種類を持つ。
packageの内側に、図の種類を1つも登録しない入口と、種類ごとの登録のfileを置く。
検査はその入口と、使う種類の登録のfileだけを読む。
関係する検査を選ぶ命令 (`scripts/test-related.mjs`) は変えず、importのつながりが実際に使う種類だけを指す形にして選ぶ数を狭める。

## 選んだ案

検査の読み方を直し、選ぶ命令はそのままにする。
登録簿 (`packages/dragon/src/kinds/registry.ts`) は種類のfileを読まず、各種類のfileが`declare module "./registry"`で登録簿の型に自分の型を足す。
検査はpackageの根の字を書かず、そのfileから見た相対の字で読む所を書く。
全ての種類を描く検査は、全ての種類を読む助けのfile (`packages/dragon/test/all-kinds.ts`) を1つだけimportする。
種類の検査が持っていたbuildした物 (`dist`) と軽い入口の確かめは、全ての種類を読む検査のfileへ移す。
時系列図と構成図も種類ごとの登録のfileに分け、既定の入口と軽い入口はどちらも今どおり最初から2つを持つ。

## 却下した案とその理由

| 案 | 却下した理由 |
|---|---|
| 公開の描く関数を非同期にし、種類を後から読む | 公開の形を壊すが、選ぶ命令は`import()`も辺としてたどるので、それだけでは選ぶ数が減らない |
| 種類ごとの入口を公開に足す | 使い所の決まっていない公開の入口を16保つことになる |
| 選ぶ命令が`import type`をたどらない | 選ぶ仕組みを変える。型の辺は登録簿の型の足し方を変えれば消せる |
| 選ぶ命令で、別の字の土台としてだけ使うdirの字はその下のcodeを指さないと数える | 選ぶ仕組みを変える |
| 表 (`test-support/related-table.json`) に全ての種類を描く検査を名指す | 検査を足すたびに表を手で直し、書き忘れると選ばれない |
| 選ぶ規則に、配管の図のfileを変えた時は配管の図の検査だけを選ぶ例外を足す | 全ての見本を描く見本帳の検査などを取りこぼすおそれがある |
