# SDKの入口が出す名前を一覧のfileで固める

## 決めたこと

外のツールやサービスが図を置くSDKの入口`@cardenelabs/dragon/embed`が出す関数と型と知らせの名前を、1つの一覧のfile (`packages/dragon/src/embed/names.json`) に並べる。
検査`sdk-entry-matches-name-list`が、build した`dist/embed.js`が出す関数と`dist/embed.d.ts`が出す型と知らせの表 (`DragonEmbedEventMap`) を一覧と突き合わせ、一覧に無い名前を出すか一覧の名前を出さないと落ちる。
名前を足すか変えるか消す時は、一覧と、版の真ん中の数と、変更の一覧 (`CHANGELOG.md`と`CHANGELOG.ja.md`) を同じPRで直す。

## 選んだ案

入口の名前を一覧のfileに置き、検査で今の入口と突き合わせる。
SDKは`@cardenelabs/dragon`の入口の1つとして出し、package と同じ版の数を使う。
外の人が使う名前を気付かずに変えると、置いた側の頁が版を上げただけで壊れるため、名前を変えたことを検査で止め、版の真ん中の数を上げて変更の一覧に書くまでを1つのPRにまとめさせる。

## 却下した案とその理由

| 案 | 却下した理由 |
|---|---|
| 1.0まで入口の約束をしない | 外の人が使う入口を気付かずに壊すことを止める物が無い |
| SDKの入口だけ別の版の数を持つ | 版を2つ持つと、どちらの版で何が変わったかを2か所で追うことになる |
| 名前の一覧を置かず、型の検査 (`tsc`) だけに任せる | 型の検査は入口の中の食い違いを見るだけで、名前を消したことも足したことも通す |
