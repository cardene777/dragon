# 配管の図の組んだ並べ方を生成物に収める

## 決めたこと

配管の図の組んだ並べ方 (`layoutPipe`の戻り値) は、書き出す命令 (`dragon export`) と`dragon embed`と見本帳のbuildが、原本から組んで生成物 (書き出したHTML、埋めた頁、buildの出力) に収める。
gitにも原本にも置かない。
収める形は、最初に見える形と、畳んだ箱を1つだけ開いた形 (箱がN個の図ではN+1通り) にする。
収めた並べ方は、`packages/dragon/src`全体から作るcodeの指紋と、原本と言葉の指紋を持つ。
ブラウザで描く時もNodeで描く時も、指紋が合う並べ方が在れば道を探さずに描き、合わない時は知らせを出さずにその場で組んで描く。

## 選んだ案

組んだ並べ方を生成物にだけ収める。
書き出す命令は、頁で描かれうる字を集めるために畳んだ箱を全て開いた形まで既に組んでいる (`packages/dragon/src/export/page.ts`の`openedTexts`) ので、収めるために並べる仕事は増えない。
生成物は自分の再生のscriptを収めるか同じbuildで作るので、並べ方を組んだcodeと描くcodeが同じbuildになり、src全体の指紋で並べ方を捨てすぎても秒数は増えない。
並べ方は原本から作り直せる物として生成物の中だけに在るので、原本と並べ方の二重管理にならない。

## 却下した案とその理由

| 案 | 却下した理由 |
|---|---|
| 作らずに閉じる | 新しいprocessでは毎回組み直し、結果を持って再実行を避けられない |
| 原本の隣のfileに置いてgitで持つ | 原本から作った写しをgitに置くので二重管理になり、並べ方のcodeを変えるたびに全てのfileを作り直す |
| 描いた端末で指紋を鍵に覚える | 各端末で初めて描く1回目は今と同じ秒数を待つ |
| 開ける形の組を全て (2のN乗通り) 収める | 箱が5個の図で32通りを組んで収めることになり、大きさと書き出す秒数が箱の数より速く増える |
| 並べ方を組む3つのfileだけを指紋に入れる | `layoutPipe`は見た目の値と字の幅と流れの計算のfileも読むので、それらを変えた時に古い並べ方で描く |
