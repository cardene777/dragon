# 字を折る幅は1行16字を下限にし、最後の行が短い時は句読点で折り直す

## 決めたこと

並べ方で幅を測って折るSVGの字 (列の図、判定の表の絵、今後字を折る図の種類) は、1行に16字入らない幅で折らない。
字数は全角に直した数で、半角は2字で全角1字に数える。
幅は字の大きさの16倍を下限にし、描き方の側でその幅まで広げて描く。
見本の検査と`dragon check --layout`は、下限より狭く折った所を止める。

折った最後の行が4字に満たない時は、前の行の最後の句読点の後で折り直す。
句読点が無い時は、行数を変えずに行の長さを均す。

ブラウザが折るHTMLの札と頁の字は見ない。

## 選んだ案

狭い列に長い字を折ると、1行が2、3語の短い行が縦に積み上がり、字がごちゃつく (#4008)。
16字の幅なら、英語は1行が5、6語、日本語の長い説明も4行に収まる。
最後の行に1、2字だけ残る形 (「12枚ま / で。」) は語の途中で切れるので、句読点で折り直すと文ごとの行になる。

## 却下した案とその理由

| 案                                                          | 却下した理由                                                  |
| ----------------------------------------------------------- | ------------------------------------------------------------- |
| 12字を下限にする                                            | 英語が1行3、4語で6行になり、縦に長い                          |
| 20字を下限にする                                            | 列の図の帯の欄の字と説明の札の幅まで直す所が広がる            |
| 決まりを置かない                                            | #4008 で退けた10字の幅も描けてしまう                          |
| 描き方は替えず、`dragon check --layout`が知らせるだけにする | 利用者の記法では狭い所に詰めた絵がそのまま出る                |
| HTMLの札と頁の字も見る                                      | 札は1行19字で決まりを満たし、頁の字は利用者の画面の幅で決まる |
| 最後の行の短さを直さない                                    | 見本に1、2字だけの最後の行が6か所残る                         |
