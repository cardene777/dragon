# 線の札の字を、札の字に在る記号で地の文とコードに分ける

## 決めたこと

日本語を含まない線の札は、札の字に`()`、`_`、`/`、`0x`、語の中の大文字のような印があるか、数で始まる時だけ等幅の字 (`TYPE.label`) で描く。
ほかの札は地の文の札として、日本語の札と同じ字と太さ (`TYPE.labelJa`、太さ650) で描く。
決まりから外れるコードの札 (例えば`git rebase main`と`git switch main`) は、札をbacktickで囲めば等幅で描く。
日本語を含む札は今までどおり`TYPE.labelJa`で描く。

決まりを当てるのは線の札 (線の名前、側道の札、枝分かれの図の札) だけで、図の下の`strip`の値は今までどおり等幅で描く。
配管の図の線の札は別の描き方で描くので、この決まりの外にある。

## 選んだ案

札の字に在る記号で見分ける案を選んだ。
課題に挙がった4つの例 (`Approve`、`Re-run every transaction in the EVM`、`transfer(Bob, 100)`、`eth_sendRawTransaction`) を全部分けられる。
配管の図を除く英語の見本の線の札233件のうち、138件が地の文の字、95件が等幅になり、backtickで囲み直す札は`git rebase main`の4件と`git switch main`の2件で済む。

## 却下した案とその理由

| 案 | 却下した理由 |
|---|---|
| 日本語を含まない札を今までどおり全部等幅で描く | 地の文の札とコードの札の見分けが付かないまま残る |
| backtickで囲んだ札だけを等幅で描く | 印を付けないコードの札が等幅でなくなり、見本の英語95件と日本語60件、合わせて155件のコードの札にbacktickを書き足すことになる |
| 地の文の札を今の等幅の札と同じ太さ600で描く | 650との差は4倍に拡大しても見分けにくく、英語の地の文の字の定義を1つ足すことになる |
| `strip`の値にも同じ決まりを当てる | `strip`の値には`e5f8`、`B 8b04f71`、`v2.4.0`のようなhashや版の値が多く、英語の見本の277件のうち24件を地の文と取り違える。見分け方は#3856で決める |
