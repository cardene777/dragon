# mdから頁を書き出す時の見出しの深さと箱の結び付け方

## 決めたこと

`dragon export <file.md>`が書く頁では、mdの見出しの深さを固定して読む。
`#`は頁の題、最初の`##`より前は入口、`##`は段、`###`は項目、`####`は入口と項目の頁の中のタブ、`#####`はタブの中のタブにする。
入口の全体の図の箱は、今の箱の飛び先の書き方で`[link: #<場所の名前>]`と書いて項目に結ぶ。
場所の名前は見出しの字から作り、無い項目を指す飛び先は書き出す時に誤りにする。

## 選んだ案

見出しの深さを文書に依らず固定し、箱の飛び先に`#`で始まる頁の中の場所も書けるようにする。
同じmdを3つの組み立て (`entry`、`sidebar`、`tabs`) のどれでも読み、書き手は見出しを付けるだけで頁が分かれる。
箱の結び付けはmdの見出しへの普通のlinkと同じ形になり、見出しの字を変えて外れた飛び先は命令が名指して断る。

## 却下した案とその理由

| 案 | 却下した理由 |
|---|---|
| 見出しの深さを文書から数え、タブの見出しの1つ上の深さを項目にする | 同じ見出しが文書ごとに別の物になり、どの深さが何かをmdから読み取りにくい |
| タブと項目を`:::tabs`のような囲みで書く | GitHubで読むと囲みの行がそのまま出て、普通のmdから離れる |
| 箱の名前と項目の見出しの字が同じなら結び付ける | 名前を少し変えると黙って外れ、名前の違う箱は結べない |
