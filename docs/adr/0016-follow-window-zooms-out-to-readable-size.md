# 寄って追う窓は、段が指す箱が収まらない段で読める大きさまで引く

## 決めたこと

寄って追う窓は、段が指す箱と線の札が今の大きさで窓に収まらない段で、窓を引いて図を縮めて見せる。
縮めるのは、箱の名前の字が読める大きさ (`READABLE_PX` = 10.5px) になる所までにする。
それでも収まらない段は、線の先の箱と線の札から先に窓へ入れ、入らない線の元の箱と枝を窓の端で切る。
切れた箱には、#3836で足した名前の札を窓の枠の内に出す。

段が指す箱が今の大きさで収まる段の窓は、今のまま縮めない。
次の段で収まれば、窓は元の大きさへ戻る。

この形は、窓の真ん中を種類が決めない全ての種類に当てる。
時系列図は窓の上に頭の列を留めるので外す。
名前の札は、今札を持つ状態の図、木の図、量の行き先の図に構成図を足す。

## 選んだ案

寄って追う形は、図の全体を枠に収めると箱の名前が10.5pxを下回る図のための見せ方で、それより小さく引くと寄って追う形を選んだ理由を崩す。
線の先の箱と線の札が窓に入れば、線がどこへ行くかは読める。
切れた線の元の箱は、名前の札で読める。

## 却下した案とその理由

| 案                                                         | 却下した理由                                                                   |
| ---------------------------------------------------------- | ------------------------------------------------------------------------------ |
| 字が小さくなっても、段が指す全ての箱と線の札が入るまで引く | 幅360で箱の名前の字が7.2pxから7.8pxになり、読める大きさ10.5pxを下回る          |
| 引かずに今の窓のままにする                                 | 状態の図の「失敗」と構成図の「記録」が窓の外に残り、線がどこへ行くかが読めない |
| 課題の3つの種類 (状態の図、構成図、木の図) だけで窓を引く  | 同じ寄せ方を使うほかの種類の収まらない段が、線の先を窓の外に残したままになる   |
