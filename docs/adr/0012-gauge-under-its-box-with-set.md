# 量の目盛りを量を持つ箱の下に置き、段の値を`set`で書く

## 決めたこと

上限のある量を段ごとに動く棒で見せる目盛りを、どの図の種類にも置ける共通の部品にする。
最初の`step`より前に`gauge <id> as <名前> [on: <箱>, limit: <数>, unit: <単位>]`で目盛りを宣言し、段の中の`set <目盛り>: <総量>`で値を書く。
段に書く値はその時の総量で、書かない段は前の段の値を保ち、前より小さい値を書くと棒が縮む。

目盛りは`on`で指した箱のすぐ下に置き、箱を指さない目盛りは図の上の帯に置く。
同じ箱を指す目盛りは、宣言した順に縦に積む。
形は横の棒と「40 / 100 USDC」の字で、上限を書かない目盛りは棒を描かず値と単位だけを出す。
上限を超えた時は、上限の位置に点線を引いて超えた分だけを赤で伸ばし、値の字を赤にして、目盛りのすぐ下に赤い札を出す。
札の字は既定で「上限を超えた」(英語は`over the limit`) にし、宣言の`[over: <字>]`で替えられる。
値が変わった段では、棒の横に増えた量か減った量 (`+20`、`−20`) を札で出す。

## 選んだ案

`set <名札>: <値>`は、量の図、集合の重なりの図、表どうしの関係の図、中身の帯で、その段の値を書き、書かない段は前の値を保つ行として使われている。
目盛りの値も同じ行で書くと、書き手の覚える語が増えない。
量を持つ箱の下に置くと、誰の量かが線を引かずに分かり、上限の線を棒の中に残すと、どれだけ超えたかが長さで分かる。

## 却下した案とその理由

| 案 | 却下した理由 |
|---|---|
| 目盛りだけの新しい語`fill <目盛り>: <総量>`で値を書く | 同じ意味の語が2つになる |
| 段の行の終わりに`[<目盛り>: <総量>]`で値を書く | 目盛りが増えるほど段の行が長くなる |
| 全ての目盛りを図の上の帯に置く | 量を持つ箱と目盛りが離れ、誰の量かが分からない |
| 図の右に縦の棒で置く | 図の幅を削り、線の名前が狭くなる |
| 上限を10に分けた刻みで塗る | 刻みの間の半端な値を描けない |
| 円の輪で割合を描く | 上限を超えた量を描けない |
| 上限を超えた時、棒を満杯で止めて「+20 超えた」を出す | 超えた量を長さで比べられない |
| 上限を超えた時、棒を全て赤で塗る | どれだけ超えたかが分からない |
| 同じ箱の目盛りを横に並べる | 隣の箱の下にはみ出す |
