# 判定の表は外れる規則だけを書き、書かない規則を✓にする

## 決めたこと

例を規則と照らした結果を見せる図の種類として、判定の表 (`judge`) を足す。
`judge <題>`で始め、`rule <id> as <名前> [value: <値>]`で列の規則を、`case <名前> [note: <添え書き>]`で行の例を書く。
例の下に`fail <規則>: <外れた値>`を書いた規則だけが✕になり、書かない規則は✓になる。
規則を照らせない時は、その`fail`の行に`[stop]`を書くと、後の列を「—」にする。

表はHTMLの表で描き、規則を列の左から1列ずつ照らしてから、行ごとに判定を出す。
✕の下に外れた値を出し、判定の「止める」の下に外れた規則の番号と名前を出す。
判定の語は既定で「通す」と「止める」(英語は`pass`と`block`) にし、1行目の`[pass: <語>, block: <語>]`で替えられる。
規則と例の数に上限を置かず、枠の幅に収まらない時は表を横に送り、例の列を左に留める。

## 選んだ案

外れる規則だけを書くと、例の行と外れる行だけで表が埋まる。
外れた値を書くのは書き手で、dragonは比べないので、累計や日付のような比べ方を部品に持たせずに済む。
1つの例が複数の規則に外れる時も、`fail`の行を足すだけで書ける。

## 却下した案とその理由

| 案 | 却下した理由 |
|---|---|
| 外れる規則を例の行の属性 (`[fail: <規則> <値>]`) に書き、1つの例を1行で終える | 外れる規則が2つ以上の時に属性の区切りが入り組み、規則と値をスペースで繋ぐ形になる |
| 規則に比べ方を、例に値を書き、✓と✕と累計をdragonが照らして出す | 例ごとに全ての規則の値を書くことになり、書く量が最も多い |
| ✕の下に外れた値だけを出す | どの規則で止まったかを読むには、✕から見出しまで目を動かすことになる |
| 見出しを番号だけにし、規則の名前と値を表の下に並べる | 番号と規則を表の下で引き比べることになる |
| 携帯の幅では例ごとのカードに替える | 規則の列を縦に見比べられず、同じ規則で止まる例を探しにくい |
| 判定の語を「通す」と「止める」に決める | 送金の審査でない題材で、判定の語が合わなくなる |
