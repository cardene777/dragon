店が注文を受けてから品物を届けるまでを、2つの段と3つの項目に分けて見る。
入口の図の箱か下の札を押すと、その項目の頁へ移る。

#### 全体の図

```dragon
architecture 注文を届けるまで [view: fixed]

box 画面 as 注文の画面 [note: 利用者が品物を選ぶ, link: #注文を受ける]
box 支払い as 支払いの仕組み [note: 代金を受け取る, link: #代金を受け取る]
box 倉庫 as 倉庫 [note: 品物を送り出す, link: #品物を送る]

step 注文を受ける
  say 利用者が画面で品物を選び、注文を送る。
  画面 -> 支払い: 注文
step 代金を受け取る
  say 支払いが済んだ注文だけを倉庫へ回す。
  支払い -> 倉庫: 支払い済みの注文
```

#### 表で見る

| 段 | 項目 | 渡す物 |
|---|---|---|
| 受付 | 注文を受ける | 注文の番号 |
| 支払いと配送 | 代金を受け取る | 支払い済みの注文 |
| 支払いと配送 | 品物を送る | 送り状の番号 |

## 受付

画面から届いた注文を受ける段。

### 注文を受ける

画面から届いた注文を受け、在庫を確かめて番号を返す。

#### 結果

在庫の在る注文だけを受け、注文の番号を返した。

> [!NOTE] 頼んだこと
> 在庫の無い品物を含む注文は受けずに断る。

| 確かめた事 | 結果 |
|---|---|
| 受けた注文 | 12件 |
| 在庫が無く断った注文 | 2件 |

#### 仕組みの図

```dragon
sequence 注文を受ける

box 利用者 as 利用者の画面
box 店 as 店の受付

step 頼む
  say 利用者が品物と届け先を送る。
  利用者 -> 店: 注文
step 番号を返す
  say 店が在庫を確かめ、注文の番号を返す。
  店 -> 利用者: 注文の番号
```

## 支払いと配送

代金を受け取ってから品物を送り出す段。

### 代金を受け取る

注文の代金を受け取り、済んだ注文を倉庫へ回す。

#### 結果

12件の注文のうち、支払いが済んだ10件を倉庫へ回した。

#### 仕組みの図

![支払いの図](parts/pay.dragon)

### 品物を送る

倉庫から品物を送り出し、送り状の番号を残す。

#### 結果

- 10件の品物を送り出した
- 送り状の番号を注文ごとに残した
