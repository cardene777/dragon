店が注文を受けてから品物を届けるまでを、問いごとに読む。
下線の語を押すと、その語の説明が札で出る。

![用語](glossary.md)

## 注文を受ける

### 店はどの注文を受けるのか

> 在庫の在る品物だけの[注文](glossary.md#注文)を受け、[注文の番号](glossary.md#注文の番号)を返す。

```dragon
sequence 注文を受ける

box 利用者 as 利用者の画面 [note: 品物と届け先を選ぶ, example: りんごを3つ、東京の家へ]
box 店 as 店の受付 [note: 在庫を確かめて番号を返す]

step 頼む
  say 利用者が品物と届け先を送る。
  利用者 -> 店: 注文
step 番号を返す
  say 店が在庫を確かめ、注文の番号を返す。
  店 -> 利用者: 注文の番号
```

在庫の無い品物を1つでも含む注文は、まとめて断る。

<details>
<summary>在庫の無い品物を1つ含む注文はどうなるか</summary>

断られる。店は注文を分けずに、まとめて断る。

</details>

<details>
<summary>受けた注文に店は何を返すか</summary>

注文の番号を返す。利用者は番号で届け先を後から確かめられる。

</details>

### 断った注文はどこに残るのか

> 断った注文は、断った訳と共に受付の記録に残る。

| 確かめた事 | 結果 |
|---|---|
| 受けた注文 | 12件 |
| 在庫が無く断った注文 | 2件 |

## 届ける

### 代金を受け取った後に何が起きるのか

> [支払い](glossary.md#支払い)が済んだ注文だけを倉庫へ回し、送り状の番号を付けて送り出す。

```dragon
architecture 代金を受け取ってから送るまで

box 支払い as 支払いの仕組み [note: 代金を受け取る]
box 倉庫 as 倉庫 [note: 品物を送り出す, example: 送り状の番号 A-1024]

step 回す
  say 支払いが済んだ注文だけを倉庫へ回す。
  支払い -> 倉庫: 支払い済みの注文
```

<details>
<summary>代金を受け取る前の注文は倉庫へ回るか</summary>

回らない。倉庫へ回るのは支払いが済んだ注文だけ。

</details>
