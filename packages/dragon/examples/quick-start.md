# 記法の書き方

dragon の図は、人は記法で書き、道具は JSON (原本) で持つ。
記法は 1 行が 1 本の線になる行ごとの文で、段の見出しの下にその段で起きることを起きる順に並べる。
書き方の全部を使った例は、同じ directory の `oauth.dragon` (時系列図) と `ccip.dragon` (構成図) にある。

## 最小の図

```dragon
時系列図 ログインを頼む

ブラウザ = 利用者のブラウザ「利用者が操作する」 [色 slate]
アプリ = アプリ「ログインを頼む側」 [色 blue]

# ログインを押す
> 利用者がアプリのログインを押す。
ブラウザ -> アプリ : GET /login
```

## 行の形

最初の段の見出し (`#`) より前に、図の種類と題、区画、箱、中身の帯を宣言する。

| 行 | 書き方 | 例 |
|---|---|---|
| 図の種類と題 | `時系列図 <題>` か `構成図 <題>` | `構成図 CCIP でトークンを送る` |
| 見せ方 | `見せ方 止める` か `見せ方 寄る`。書かなければ、全体を枠に収めた時の字の大きさで選ぶ | `見せ方 寄る` |
| 区画 | `区画 <名札> = <名前>「<添え書き>」` | `区画 送信元 = 送信元チェーン「例 Ethereum」 [色 blue]` |
| 箱 | `<名札> = <名前>「<下の小さな字>」` | `OnRamp = OnRamp「確かめて送り出す」 [区画 送信元]` |
| 中身の帯 | `帯 <題> = <欄>, <欄>` | `帯 メッセージ = ID, 宛先, 状態` |

段の見出しの下には、次の行を起きる順に並べる。

| 行 | 書き方 | 例 |
|---|---|---|
| 段の題 | `# <題>` | `# トークンを預ける` |
| 段の本文 | `> <本文>`。2 行以上に分けてよい | `> OnRamp が Token Pool を呼ぶ。` |
| 段で打つ命令 | `` `<命令>` ``。1 つの段に 1 行まで | `` `lockOrBurn()` `` |
| 線 | `<名札> -> <名札> : <線の名前>`。名前は省ける | `OnRamp -> 送信元Pool : lockOrBurn() [硬貨]` |
| 箱の中の処理 | `<名札> : <処理の名前>` | `OnRamp : 中身を確かめる` |
| 箱の下の字の書き換え | `<名札>「<字>」` | `送信元Pool「−100 USDC」` |
| 中身の帯の値 | `帯 <欄> = <値>` か `帯 <欄> [<札>]` | `帯 状態 = SUCCESS` |

`止める` は全体を止めて中だけ動かし、`寄る` は今動いている所へ寄って動かし、隅の全体図で今どこかを示す。
書かない時は、全体を枠に収めた字が 10.5px 以上なら `止める`、下回るなら `寄る` になる。

段には本文が要る。
読み上げの道具は、段の題と本文を段の順に読む。

## `[...]` の指定

行の終わりに `[<鍵> <値>]` を並べて、見た目と運ぶ物を指定する。

| 付ける行 | 指定 | 意味 |
|---|---|---|
| 区画と箱 | `[色 <色>]` | 色の役。`blue` / `amber` / `green` / `violet` / `rose` / `slate` / `coin` のどれか |
| 区画と箱 | `[印 <印>]` | 名前の横に置く印 |
| 箱 | `[区画 <名札>]` | 箱を置く区画。区画は先に宣言する |
| 線 | `[札 <値>]` / `[硬貨]` / `[なし]` | 線の上を走る物。書かなければ封筒が走る |
| 線 | `[名前 上]` / `下` / `左` / `右` | 線の名前を置く側。自動で決めた置き場所が崩れた時だけ書く |

`//` で始まる行と空行は読まない。
行の頭の空白も意味を持たない。

## 文書に埋め込む

README や記事の中では、言語を `dragon` にした囲みに書く。
1 つの文書に何枚でも埋め込める。

````markdown
```dragon
時系列図 ログインを頼む
...
```
````

## JSON との行き来

記法と JSON は行き来できる。
JSON から記法へ書き戻す時は決まった並べ方に整えるので、書き手の行の並べ方とコメントは残らない。
JSON の形は `src/schemas/diagram.schema.json` が持ち、`version` の欄に形式の版を書く。
