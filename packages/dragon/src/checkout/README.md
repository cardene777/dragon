# 購入図の部品

通常の図種としての入口は`../kinds/checkout.ts`。
解析・描画・操作は本体の`parseNotation`、`renderDiagram`、`mountDiagram`を使う。

購入条件の再計算、支払い処理、注文照会の待機中は見出しと操作ボタンにローディング表示を出す。
購入者の承認待ちと、注文照会をまだ開始していない応答不達では回転させない。
動きを減らす設定では回転を止め、待機を示す円と文言は残す。

操作画面の注文照会は`RECONCILE_START`で`reconciling`へ進み、返答後の`RECONCILE`で注文を確認する。
照会中は購入条件を変更できず、照会を重ねても注文数と決済回数は増やさない。
セッションが変わった後の古い返答は無視する。
