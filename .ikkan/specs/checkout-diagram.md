# 購入操作図と共通ヘッダー

| 条件 | 確かめ方 | 出元 |
|---|---|---|
| `checkout`の記法を標準入口で解析し、JSON保存と記法出力から再読込できる | `dragon-native.test.mjs`の往復変換の検査 | #3677 |
| 配送や数量の変更で以前の承認を無効にし、決済拒否と応答不達でも注文と決済を重複させない | `acp-purchase-lab.test.mjs` | #3677 |
| ヘッダーの上段に題、コード、dragonで開く、書き出す、拡大をこの順で置く | `article-frame.test.ts`の共通ヘッダーの検査 | #3677 |
| 再生や配色の既存操作を下段へ置く領域を持ち、操作が無い時は下段を隠す | `createFigureHeader`と埋め込み先の表示確認 | #3677 |
| 埋め込み先から背景、文字、線、強調色を指定でき、コード窓でも親の配色を保持する | `article-frame.test.ts`とブラウザでの配色切替 | #3677 |
| 画面全体の幅に関わらず、ヘッダーの置かれた領域が狭い時は操作を折り返す | 共通ヘッダーのコンテナークエリーと幅390pxの表示確認 | #3677 |
| 公式エディタへ日本語を含む記法の全文を渡し、コードは構文色を付けて表示する | `article-frame.test.ts` | #3677 |
| PNG・SVGは操作欄を含む全体、HTMLは初期条件から操作できる単独ファイル、GIF・MP4は直近の操作履歴を書き出す | 書き出しの実動作確認と`article-frame.test.ts` | #3677 |
| 中央寄せの余白を複製後も保持し、動画のコマごとの横ずれを防ぐ | `article-frame.test.ts`の余白検査 | #3677 |
| 保存したブロックの行番号は2から10000までの整数を受け、それ以外は空行へ展開する前に拒否する | `dragon-native.test.mjs`の行番号の拒否検査 | #3677 |
| 標準の図の解析・描画と初期読込量の上限を守る | `pnpm test:related`と`script-entry.test.ts` | #3677 |

図の入力、条件判定、記法とモデルの変換は購入図の部品が持つ。
共通ヘッダーの軽い入口は描画本体を読み込まず、埋め込み先の再生操作を受け取る。
実決済とカード認証は行わない。
